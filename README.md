# LiDAR Odometry from Scratch

A step-by-step implementation of LiDAR odometry
and LiDAR-Inertial Odometry (LIO).

## Project Goals

- Understand point-cloud registration mathematically.
- Implement ICP and estimate relative sensor poses.
- Build a sequential, timestamp-aware odometry pipeline.
- Integrate IMU measurements into LiDAR odometry.
- Implement the core algorithms in C++17.
- Evaluate trajectory accuracy and runtime.

## Development Roadmap

- Phase 0: Synthetic point clouds and ICP in Python.
- Phase 1: ICP implementation and evaluation.
- Phase 2: Sequential LiDAR odometry.
- Phase 3: IMU fundamentals and integration.
- Phase 4: LiDAR-Inertial Odometry.
- Phase 5: C++17 implementation and optimization.
- Phase 6: Dataset evaluation and ROS 2 integration.

## Technologies

- Python, NumPy, SciPy, Matplotlib
- C++17, Eigen, CMake
- ROS 2 (planned)
